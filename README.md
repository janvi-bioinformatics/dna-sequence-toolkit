# 🧬 DNA Sequence Analysis Toolkit

A Python-based bioinformatics toolkit for analyzing DNA sequences.  
This project provides multiple utilities for working with DNA, including transcription, mutation detection, and protein translation.

---

## 🚀 Features
- 🔢 Base counting (A, T, G, C)
- 🧪 GC content calculation
- 🔁 DNA → RNA transcription
- 🔄 Reverse complement generation
- 📍 ATG start codon finder
- 🧬 DNA → Protein translation
- ⚠️ Mutation detection between two sequences
